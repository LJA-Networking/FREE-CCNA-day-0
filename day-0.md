# FREE-CCNA-day-0

* Internet is just a bunch of routers, switches and firewalls
* Goes from router to router to a server where it then is transmitted to the end user
* Allows computers to share and communicate data with each other
* First started with computer to computer
* Then went to computer to switch to computer
  * At some point too much load on switches
  * Spread the load over many switches
* Start using routers to connect switches
  * Allows for different switches to connect and communicate
* Starts to build the internet
 
* Firewall job is to secure networks
* Block unwanted inbound/outbound connections
 
* WAP (Wireless AP)
   * Serves as switch, router and firewalls
